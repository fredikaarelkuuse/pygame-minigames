# pygame-minigames

Fredi Kaarel Kuuse (kasutajanimi: fredikaarelkuuse) ja Mihkel Põldvere(kasutajanimed: MihkelP100 ja fresh480) programmeerimise projekt.  
Meie projekti eesmärk on luua Pygame'i abil väike kogu lõbusaid mänge ning anda neile ülikooliga seotud stiil / temaatika.

# Kasutusjuhend
Mängude mängimiseks on vajalik Mainmenu.py, game1.py ja mäng.py. Menüüs liikumine on veel poolik. Menüü kasutamiseks käivitage Thonnys Mainmenu.py, sealt saab valida hetkel vaid ühe mängudest, ning mängust menüüsse tagasi veel ei saa. Teisi mängu mängimiseks käivitage mäng.py Thonnys.
